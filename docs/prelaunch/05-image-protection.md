# 05. 이미지 보호 — 재검토와 결정

- 작성·적용: 2026-10-26
- 결정: **전역 차단 제거(완화) + 실사 사진 워터마크**

## 1. 이전 구조 (작가 사이트에서 가져옴)

1. `GlobalProtection`: 문서 전체에서 우클릭(`contextmenu`)·드래그(`dragstart`) 차단
2. CSS: 모든 `img`에 `pointer-events: none` + 선택 금지
3. 이미지 위 투명 덮개 div (`.img-protected::after`, 갤러리 덮개)

## 2. 회사 홈페이지에서의 문제

| 영향 | 내용 |
|---|---|
| 사용성 | 우클릭이 **문서 전체**에서 막혀 링크 "새 탭에서 열기", 문의 폼 붙여넣기·맞춤법 메뉴, 주소·전화 복사까지 차단 |
| 접근성 | 화면 확대·번역·읽기 도구 등 우클릭·드래그를 쓰는 보조 기능 방해 |
| 보호 효과 | 낮음 — 개발자 도구, 화면 캡처, 이미지 주소 직접 열기로 쉽게 우회 |
| 목적 | 회사 사이트에서는 사진이 공유되는 것이 홍보가 되는 경우가 많음 (작품 사이트와 우선순위가 다름) |

## 3. 비교

| 방식 | 보호 효과 | 사용성 | 결정 |
|---|---|---|---|
| 유지 | 낮음 | 나쁨 | ✗ |
| 완화 (전역 차단 제거, 이미지 드래그·선택만 방지) | 낮음 | 좋음 | ✓ |
| 워터마크 (사진 귀퉁이에 출처 표시) | 출처 표시 효과 | 영향 없음 | ✓ (함께 적용) |

## 4. 적용 내용

- 삭제: `components/GlobalProtection.tsx`, `components/ProtectedImage.tsx`, 갤러리 투명 덮개, `.img-protected` CSS, 이미지 `pointer-events: none`
- 유지: 이미지 드래그·선택 방지 (`draggable={false}`, CSS `user-drag` / `user-select`) — 갤러리를 끌 때 사진이 딸려 나오지 않도록
- 워터마크: `scripts/process-images.mjs`
  - 대상: **실사(`ing-*`) 83장만** — 회사가 직접 찍은 제작 현장 사진
  - 렌더 제외: 실내 분위기 샘플(`in-*`)은 아파트 샘플 렌더, 외관 콘셉트(`out-*`)는 출처 확인 전 → 회사 이름을 넣으면 회사 제작물처럼 보일 수 있음
  - 모양: 오른쪽 아래, 짧은 변의 2.6% 크기 "CW_ArtHouse", 흰색 55% + 옅은 그림자
  - 끄기: `npm run images -- --no-watermark` (원본 `assets-src/`는 그대로라 언제든 다시 생성 가능)
  - 결과 확인: `docs/image-report.md`의 "워터마크" 열

## 5. 주의

- 주석 마커(제작 과정 페이지)가 사진 오른쪽 아래에 있으면 워터마크와 겹칠 수 있습니다 — 현재 7장의 마커는 겹치지 않음.
- 워터마크 문구·위치를 바꾸려면 `scripts/process-images.mjs`의 `WATERMARK` · `watermarkSvg()`를 고친 뒤 `npm run images`.
