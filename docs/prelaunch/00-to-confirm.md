# 확인해 주셔야 할 것 (2026-10-26)

배포 전 점검(15단계) 뒤 남은 확인·결정 사항입니다. 처리한 항목은 `[x]`로 바꿔 주세요.

## 1. 배포 전에 꼭 필요한 것

- [ ] **사이트 주소(도메인)** → 환경변수 `NEXT_PUBLIC_SITE_URL`
  - 지금은 비어 있어서 링크 공유 시 미리보기 이미지 주소가 localhost로 나옵니다.
- [ ] **프로젝트명** → `lib/projects.ts`
  - 지금은 상세 페이지 제목이 "[확인 필요]"로 보입니다.
- [ ] **문의 접수 방식** → `NEXT_PUBLIC_FORM_ENDPOINT`(폼 전송 서비스) 또는 `NEXT_PUBLIC_CONTACT_EMAIL`(이메일)
  - 폼 전송 서비스를 쓰면 동의 문구에 개인정보 국외 이전 고지가 추가로 필요합니다.
  - 둘 다 없으면 전송 버튼이 꺼진 채 "온라인 접수 준비 중"으로 표시됩니다.
- [ ] **개인정보 동의 문구** → 사전 파일 `contact.form.consentItems`
  - 보관 기간과 처리 책임자가 필요합니다.
- [ ] **검색 노출 시작 시점**
  - 지금은 모든 페이지가 검색에 안 잡히도록 막혀 있습니다(`noindex`).
  - 도메인과 프로젝트명이 정해진 뒤에 푸는 것을 권장합니다 ([02-seo.md](02-seo.md) 3절).

## 2. [확인 필요] 내용 채우기

자세한 표는 [01-content-checklist.md](01-content-checklist.md)에 있습니다.

- [ ] 회사 정보: 상호, 사업자등록번호, 건설업 등록, 주소 → `lib/company.ts`
- [ ] 연락처: 전화, 이메일, 카카오톡 채널 → `lib/company.ts`
- [ ] 사양: 면적, 단열, 가격, 공사 기간, 운송 방법, A/S
- [ ] 공정별 확인 항목 31건 → `lib/projects.ts`의 `tbc()` 항목
- [ ] 확인이 필요한 공정 내용 3가지
  - 기초 고정 방식
  - 벽체 패널의 성능·두께
  - 돌출부가 어떻게 동작하는지
- [ ] 사진 속 표시 2가지: 연필 표시와 파란 보드가 무엇인지
- [ ] 철학·특징 문구 초안 검토 (회사 소개 페이지)
- [ ] 준비 중 사진 12컷 (제작 과정 페이지의 "준비 중" 자리)
